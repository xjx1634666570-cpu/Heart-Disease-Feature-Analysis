# Heart Disease Prediction Project

## 📌 Project Overview
This project aims to predict the likelihood of heart disease based on clinical and lifestyle variables. 
It uses an interactive Streamlit application to explore the data, visualize correlations, and demonstrate 
the impact of feature engineering on heart disease prediction.

## 📂 Data Source
The dataset (`heart_disease.csv`) contains approximately 10,000 records with the following key variables:
- **Demographics:** Age, Gender
- **Clinical Metrics:** BMI, Blood Pressure, Cholesterol Level, Triglyceride Level, Homocysteine Level
- **Lifestyle Factors:** Smoking, Alcohol Consumption, Exercise Habits, Stress Level, Sleep Hours
- **Target Variable:** Heart Disease Status (Yes/No)
